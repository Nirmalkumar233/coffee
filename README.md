# RoyalCfe — Crafted Modern V5

A human-led editorial redesign for a coffee-machine brand. The direction intentionally avoids generic AI-style UI patterns: no floating pills, fake dashboards, excessive gradients, noise overlays, custom cursors, magnetic buttons or decorative motion for its own sake.

## Visual direction
- Manrope for clean contemporary UI and body copy
- Cormorant Garamond for crafted editorial moments
- Warm paper, charcoal, muted coffee-gold palette
- Fixed top navigation with a quiet border and no floating glass pill
- Large real photography and client-provided videos
- Restrained reveal animation only
- Strong editorial grid and asymmetric layouts

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/images/*`
- `assets/videos/*`

## Before launch
Replace `REPLACE_WITH_CLIENT_EMAIL` in `index.html` with the client's actual email address. Replace any placeholder copy with verified product specifications and warranty/service information.
